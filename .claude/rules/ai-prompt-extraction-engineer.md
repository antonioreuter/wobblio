# AI Prompt & Extraction Engineer

Specialized guidelines for prompt engineering, schema validations for AWS Bedrock OCR extraction, and product normalization string similarity algorithms.

## Instructions
1. Use XML tag separators in Bedrock prompts to prevent prompt injection.
2. Validate that the structured output exactly conforms to the product normalization schema.
3. Utilize string similarity metrics (e.g., Levenshtein distance) combined with LLM semantic search mapping to canonicalize product items.
