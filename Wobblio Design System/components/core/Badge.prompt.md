Status pill — label a record's state with a tinted, uppercase capsule.

```jsx
<Badge tone="success">Processed</Badge>
<Badge tone="warning">Needs Review</Badge>
<Badge tone="primary">Auto Parsed</Badge>
```

Tones: `primary` (indigo), `success` (teal), `warning` (amber), `danger` (coral). Each renders a translucent glow background with matching border.
