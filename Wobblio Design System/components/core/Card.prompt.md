Frosted-glass panel — wraps metrics, tables, forms and feature blocks. The signature Obsidian Aurora surface.

```jsx
<Card>
  <h3>Smart Recommendations</h3>
  <p>You can save up to €24.80 by shopping at Jumbo Oostpoort.</p>
</Card>

<Card interactive>Lifts and glows on hover</Card>
```

Default padding is `--space-6` (24px). Pass `interactive` for hover lift used on clickable cards (feature grid, use-case tiles).
